## Возможности

- **Вместо Пуска.** Открывается по `Win` (или любой другой клавише) мгновенно, даже поверх игр.
- **Своя кнопка Пуск.** На панели задач Windows 11 вместо логотипа Windows наш значок (ромб, сетка, строки или своя картинка), клик открывает лаунчер. Правый клик по-прежнему открывает меню Win+X. Выключается в настройках.
- **Сейчас играет.** На панели задач обложка, название и исполнитель из любого плеера (Spotify,
  Яндекс Музыка, браузер) и кнопки «назад», «пауза», «вперёд». Клик по названию открывает плеер,
  длинные названия прокручиваются при наведении. Слева или справа, выключается в настройках.
- **Приложения.** Всё из меню Пуск, включая приложения из Microsoft Store. Чем чаще вы что-то
  запускаете, тем выше оно в списке.
- **Файлы.** Поиск по всему диску через [Everything](https://www.voidtools.com/), он уже встроен.
  Если у вас свой Everything, лаунчер работает с ним и не индексирует диск второй раз. Самые нужные
  файлы наверху, мусор из кэшей и служебных папок внизу. Список листается до конца, сколько бы
  файлов ни нашлось.
- **Не та раскладка.** `rfkr` найдёт Калькулятор, `сщву` найдёт VS Code.
- **Английские имена.** `notepad`, `cmd`, `regedit`, `calc` находят Блокнот, Командную
  строку и остальное на русской Windows.
- **Команды.** Блокировка, сон, перезагрузка, выключение, выход, корзина. Опасные просят
  второй `Enter`.
- **Плавно и аккуратно.** Мягкое появление, выделение и меню двигаются плавно. Скорость каждой
  анимации настраивается.
- **Запуск от администратора по желанию.** Программы открываются с обычными правами, а для
  нужной есть отдельный пункт.
- **Приватно.** Без ИИ, без сети, без телеметрии.

## Установка

1. Скачайте `MixLauncher-Setup.exe` со страницы [Releases](https://github.com/mel1x/mixlauncher/releases).
2. Запустите установщик. Значок лаунчера появится в трее.

Everything ставить отдельно не нужно: в установщик входит Everything 1.5. Он запускается скрыто,
без значка в трее, и хранит индекс в `%LOCALAPPDATA%\MixLauncher\Everything`.

## Сборка

Нужен MinGW-w64 (MSYS2) или Visual Studio Build Tools, для установщика — [Inno Setup 7](https://jrsoftware.org/isdl.php).

- `build.bat` — `build\mixlauncher.exe`, `build.bat dev` — то же без запроса прав администратора.
- `release.bat` — скачивает Everything (версия и SHA-256 закреплены в `tools\fetch-everything.ps1`),
  собирает лаунчер и `build\MixLauncher-Setup.exe`. Версия берётся из `res\mixlauncher.rc`.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Win` | открыть или закрыть (`Win+E`, `Win+R` и другие работают как обычно) |
| `↑` `↓`, `PgUp` `PgDn` | выбор |
| `Tab` | следующая секция |
| `Enter` | открыть |
| `Ctrl+Enter` | показать в папке |
| `Ctrl+Shift+Enter` | запустить от имени администратора |
| `Alt+Enter` | свойства |
| `Ctrl+C` | копировать путь |
| `Esc` | очистить запрос, повторно закрыть |
| ПКМ | меню действий |
| `Ctrl+,` | настройки |

Пустой запрос показывает часто используемые приложения, недавние файлы и все приложения.

## Настройки

Кнопка Настройки в углу лаунчера, `Ctrl+,` или меню значка в трее. Всё применяется сразу.

- **Общие.** Клавиша вызова, автозапуск, сколько помнить последний запрос.
- **Внешний вид.** Тема, фон (стекло, акрил, сплошной), размер окна.
- **Анимация.** Скорость и длительность каждой анимации, кнопка для проверки и сброс.
- **Поиск.** Сколько показывать приложений, с какого символа искать файлы, фильтр Everything.
- **Дополнительно.** Очистка истории, файл настроек и папка данных.

Клавишей вызова может быть одна клавиша (`Win`, правый `Ctrl`, `F13`) или сочетание
(`Alt+Space`, `Win+D`). Прежнее действие сочетания при этом отключается.

Настройки хранятся в `%LOCALAPPDATA%\MixLauncher\config.ini`.
